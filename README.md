# LocaLoco

LocaLoco is a platform for discovering and supporting independent local
businesses in Singapore: built on a Bun + Hono backend with a React 19 SPA
(TanStack Router, Vite, Tailwind CSS v4) frontend.

## Quick Start

```bash
# 1. Install dependencies
bun install

# 2. Configure environment (copy and fill in values)
cp .env.example .env

# 3. Start development server (Frontend: 4000, Backend: 4001)
bun dev
```
